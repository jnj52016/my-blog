我写文章，第一要务是前后有关联，句子和句子有关联，上一段和下一段有关联。
明白这个，就可以写流水账了，之后就慢慢进步了。

计算机的话，我认为最简单的入门是，先去理解IPO（Input - Process - Output / 输入 - 处理 - 输出）。
不管你是写一行极简的代码，还是写一个像微信那么复杂的软件，它永远只有这一种基本结构：

1. **Input（拿接力棒）：** 从上一行代码（或者用户那里）拿到数据。
    
2. **Process（跑一段路）：** 把这个数据加减乘除，或者改变它的形状。
    
3. **Output（交接力棒）：** 把处理好的数据，交给下一行代码。

理解了这个，就可以根据原理，慢慢去学习写代码了。
