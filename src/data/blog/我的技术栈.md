## 基础

JavaScript：我的主要开发语言。毕竟我是前端出生。
 
Node.js：方便我用 pnpm init 开项目，pnpm install 安装包，使用 import 。

typescript：ts，众所周知，ts 有各种含义，政治的、计算机的、lgbt的。当然，在前端中，ts 一般用来做类型标注。

git：总之，是必会的东西。

logseq：用来管理任务的 markdown 工具，很好用。我个人喜欢。
